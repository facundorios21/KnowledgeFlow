# KnowledgeFlow — AI Microservice (FastAPI / Python)

Internal AI microservice built with **Python 3.11+** and **FastAPI**.

## Responsibilities
- Text extraction from documents (PDF, TXT, DOCX) and normalization.
- Configurable chunking with overlap.
- Embedding generation using Google Gemini API (`text-embedding-004` or latest model).
- Vector similarity search & RAG context building.
- LLM interaction with strict prompt isolation against prompt injection.
- Autonomous AI Agent with explicit tool calling.
- Internal service-to-service authentication.

Will be initialized and implemented in **FASE 5**.
