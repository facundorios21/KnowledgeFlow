# KnowledgeFlow — Backend Service (NestJS)

Main backend application built with **NestJS** and **TypeScript**.

## Responsibilities
- Keycloak OIDC JWT validation via JWKS & RBAC authorization.
- Document management (upload, metadata, access control).
- BullMQ asynchronous job orchestration with Redis.
- WebSockets for realtime document processing state updates.
- Internal communication with the Python AI Service.
- Mongoose models (Users, Documents, DocumentChunks, Conversations, Messages).
- Swagger OpenAPI documentation.

Will be initialized and implemented in **FASE 1**.
