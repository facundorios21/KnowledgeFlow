# KnowledgeFlow — Frontend Application (React)

Client-side Single Page Application built with **React**, **TypeScript**, and **Vite**.

## Responsibilities
- OIDC Authentication flow via Keycloak (Authorization Code + PKCE).
- Document repository management UI (Upload, Search, Filter, Details).
- Interactive Chat UI with RAG citations and response streaming.
- Dashboard with processing statistics and activity feed.
- Admin panel for users and system status.
- Real-time updates via WebSockets.

Will be initialized and implemented in **FASE 12**.
